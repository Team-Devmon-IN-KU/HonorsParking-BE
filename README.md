## 핵심 기능
- 현재 주차요금 확인 기능
- 입/출차 시 알림 기능
- 주차장 찾기 및 검색 기능

## 프로젝트 설명

📢 <strong>아너스파킹</strong> 은 아너스 코리아 주차장 이용자들의 주차 현황을 한눈에 볼 수 있는 서비스입니다.

✔️ 쉽고 빠른 요금 확인 <br />
✔️ 편리한 주차장 검색 <br />
✔️ 주차이력 조회 및 푸쉬/카카오톡 알림까지!
